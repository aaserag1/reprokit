# ReproKit v0.1.0

أول إصدار عام من ReproKit: أداة CLI محلية تنشئ مسودة بلاغ قابلة للمراجعة لمشكلات المشاريع.

## أبرز ما يتضمنه الإصدار

- توليد ملفي `repro.md` و`repro.json` محليًا دون رفع أي بيانات.
- اكتشاف بيانات وصفية آمنة لمشاريع Node وPython وGo وRust.
- إدراج أسماء manifest وبصمات SHA-256 لملفات lockfile وإصدارات runtimes وحالة Git المختصرة.
- استبعاد محتوى الشيفرة وملفات `.env` وGit remotes وdiffs وسجل commit من المخرجات.
- تنقيح أنماط شائعة للأسرار مثل GitHub tokens ومفاتيح AWS وJWT وبيانات URL الحساسة قبل الكتابة.

## التثبيت والتشغيل

```bash
npx @aaserag/reprokit --output .reprokit --title "Build fails after dependency update"
```

راجع الملفات الناتجة يدويًا قبل مشاركتها في أي بلاغ.

## ملاحظات الإصدار

هذا إصدار Beta مبكر. نرحب بتغذية راجعة من maintainers حول البيانات المفيدة افتراضيًا وما الذي يجب ألا يُجمع مطلقًا. لا ينفذ ReproKit اختبارات المشروع أو ينشئ Issues أو يرفع ملفات تلقائيًا.
